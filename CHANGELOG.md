# Changelog

All notable changes to [Liminal AI](https://github.com/traidy2222/liminal-ai) are documented here and on [vireondynamics.com/liminal/changelog](https://vireondynamics.com/liminal/changelog).

Format: pre-release milestones (alpha → beta → rc) then public **v0.1.0**. Dates are the last push to `main` for each milestone on GitHub (~130 commits grouped, not per-commit).

## [v0.1.0] — 2026-05-23 — Public preview

First public release. MIT license. `liminal` CLI + install scripts.

- **Install:** `liminal setup|doctor|web|tui|update`, one-command install.sh / install.ps1
- **Harness:** full ReAct loop, streaming writes, reasoning budget, two-tier routing, Task Worlds
- **Tools:** 140+ across lazy families (files, shell, git, browser, vault, documents, orchestration, …)
- **UI:** Ink TUI + web SSE with persona bootstrap and themed shells
- **Eval:** 22 scenario packs with JSON sink

[Full notes](https://vireondynamics.com/liminal/changelog/v0-1-0)

## [v0.1.0-rc] — 2026-05-22 — Production harness

- Streaming large-file writes + resume manifests
- Reasoning budget, external think/reason surface, intent routing
- Playwright browser + CAPTCHA; document engine (PPTX/DOCX/PDF)
- MIT license, compensation ledger, orchestration DAG, self_telemetry, rename_symbol
- Recipe library v2, settings catalog, SSE resilience

[Full notes](https://vireondynamics.com/liminal/changelog/v0-1-0-rc)

## [v0.1.0-beta] — 2026-05-15 — Persona, memory & orchestration

- Persona generation, bootstrap, PersonaUiTheme, web shells
- Harness settings (~190 keys), JSONL sessions, auto-dream scanner
- World context, rule recall, expanded eval packs
- Dynamic tools, MCP, sub-agent orchestration

[Full notes](https://vireondynamics.com/liminal/changelog/v0-1-0-beta)
